## Priority Issues

### [P0] Month SelectContent is Empty — Core Workflow Broken
- `<SelectContent>{/* 12 month items */}</SelectContent>` — comment placeholder, never implemented. Dropdown renders blank.
- **Fix:** Render 12 `<SelectItem>` with Indonesian month names (Januari–Desember).

### [P0] No Duplicate Period Guard
- `handleGenerate` POSTs without checking if period already generated. May overwrite/duplicate payroll records silently.
- **Fix:** Check existence before POST. If period exists, show destructive confirmation: "Periode ini sudah digenerate. Generate ulang akan menimpa data lama."

### [P1] Zero-Salary Edit Without Confirmation
- Schema `min(0)` allows zeroing any employee salary. No confirmation. HR can accidentally zero salary → employee gets no pay next cycle.
- **Fix:** Change schema to `min(1)` or show destructive confirmation when `gapok === 0`.

### [P1] Generate Button Placement Wrong Mental Model
- "Generate Gaji" inside "Daftar Pegawai" card header implies it operates on filtered list. Actually generates for ALL active employees.
- **Fix:** Move to page-level action bar. Add scope note in dialog: "Berlaku untuk seluruh pegawai aktif (bukan filter saat ini)."

### [P2] No Empty Salary Callout
- `gapok = null` and `gapok = 0` both render "Rp 0". HR cannot identify unconfigured employees before Generate.
- **Fix:** Badge "Belum diatur" (amber) for `gapok === null`. Quick filter: "Tampilkan hanya tanpa gapok."

### [P3] Generate Result No Scope Feedback
- Success toast shows generic message — user doesn't know how many employees were processed.
- **Fix:** Show count: "Berhasil generate gaji untuk 187 pegawai aktif."
